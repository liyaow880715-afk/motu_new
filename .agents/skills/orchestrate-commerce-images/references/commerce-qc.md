# 电商视觉审核与重试

## 规划标准

每个 section 先回答四件事：目标消费者是谁、当前犹豫是什么、这张图提供什么单一证据、看完要发生什么。场景、文案、镜头和标题都服务于同一个漏斗任务。

Primary Prompt 使用中文，并至少包含：

1. 商品和人物/手部正在发生的真实动作。
2. 可识别的具体环境，不用“高级感背景”这类空词。
3. 前景、中景、背景与主体占比。
4. 光源方向、色温、对比度、阴影密度和整套色板关系。
5. 标题负空间和文字层级，不要求模型重写包装小字。
6. 当前 section 的权威参考图职责与不可改变项。
7. 禁止的错误构图、虚构事实、包装重绘和横切面重塑。

## 标题策略

标题结构优先使用“购买钩子 + 单一利益/证据”，而不是品类名、模块名或说明句。

- 弱：`美味水饺`、`产品细节`、`包装展示`。
- 强：`一口咬开 鲜香看得见`、`薄皮兜住扎实好馅`。
- 事实限定：只有标签或分析中的高置信证据才能写数字、产地、成分、认证和功效。
- 免责声明：`以包装为准、详见包装` 放角落小字，不充当主标题。

主标题通常 4-14 个汉字、最多 2 行；副标题补证据，不复述主标题。缩略图下仍要看清主体和钩子。

## 视觉冲击力与统一色调

冲击力来自清晰的视觉层级，不来自堆叠饱和色、徽章和大字：

- 商品主体与背景建立明度或冷暖反差。
- 只保留一个最大视觉焦点和一个次级证据。
- 通过近景尺度、对角线动作、蒸汽/飞溅等真实瞬间增强动势。
- 标题必须落在真实负空间，不盖住商品和包装。

整套图锁定：主色 1 个、辅助色 1-2 个、强调色 1 个、统一色温、主光方向、黑位和阴影密度。场景可变，但这些参数不能每张重置。第一张人工通过的高风险图作为色调锚点。

## 硬审核维度

- `productIdentity`：主体轮廓、比例、表皮/材质、颜色与主图一致。
- `referenceBinding`：实际参考图 ID 包含所有必要素材，职责没有互相覆盖。
- `packagingFidelity`：外形、正反方向、Logo、色块、文字方向和标签层级一致；小字不可杜撰。
- `crossSectionFidelity`：开口外轮廓、皮厚、馅料颜色/颗粒/水分、朝向和筷子方向一致；不得规则化、镜像或与其他图平均。
- `toneConsistency`：色温、主光、对比度、色板面积和锚点连续。
- `sceneFit`：真实可拍、动作可信、环境服务于模块目标。
- `copyAccuracy`：标题有钩子，副文案有证据，没有错字或虚构信息。
- `typography`：层级、字重、断行、留白和对齐具有设计感，不像默认字幕。
- `thumbnailImpact`：缩小后 2 秒内能识别商品、核心钩子和主层级。
- `factuality`：数字、成分、产地、认证和功效均有来源。

任何人工维度失败，都不能被平均总分抵消。

## 定向重试矩阵

| 失败维度 | 先改什么 | 推荐动作 | 不要做 |
|---|---|---|---|
| referenceBinding | 必要参考图 ID、唯一权威图 | regenerate | 重复同一请求 |
| packagingFidelity | 包装权威图、不可改项、正反方向 | regenerate | 基于错误包装继续 edit |
| crossSectionFidelity | 唯一横切面、开口/皮/馅/方向锁 | regenerate | 同时传多张冲突切面 |
| sceneFit | 环境、动作、景别、空间层次 | regenerate | 只加“更高级” |
| copyAccuracy | 钩子、事实来源、文字预算 | regenerate/edit | 重写包装标签 |
| typography | 留白、层级、断行、字重 | edit | 改动商品结构 |
| toneConsistency | 色板、色温、主光、锚点 | regenerate | 每张独立选色 |
| thumbnailImpact | 主体尺度、明暗反差、焦点数量 | regenerate | 叠加更多徽章和文案 |

每次重试记录一个主失败原因和可验证的修复目标。连续三次失败后停止自动尝试，保留候选图并交给用户决策。
